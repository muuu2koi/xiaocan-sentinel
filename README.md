# xiaocan-sentinel

一个第三方开源的小蚕惠生活返利活动监控工具。它不修改小蚕 App 本身，也不干预任何下单行为，只是在后台安静地盯着你附近的返利活动，有新活动、或者你关注的店补货时，往手机通知栏推一条消息。

## 为什么写这个

小蚕的返利活动是随机上架的，App 内没有任何上新通知。经常是我常吃的那几家刚挂出来，名额几分钟就被抢完，等我打开 App 已经没了。所以写了这个东西：让手机替我盯着，上新第一时间弹通知。

## 功能

- 附近活动浏览：按手机定位展示周边返利活动，样式对齐小蚕首页（店名、距离、满返金额、剩余名额、抢购时段）
- 后台巡检：前台服务按可配置间隔（默认 3 分钟，带随机抖动）轮询活动列表
- 上新提醒：任何新活动出现即推送（可关）
- 关键词监听：维护自己的店铺关键词列表，模糊匹配（忽略括号、间隔号、空格差异），命中新活动或补货（名额从 0 恢复）时推送（可关）
- 夜间静默：静默时段内完全不发请求
- 异常退避：连续失败指数退避，10 次后自动暂停
- 免登录：未登录状态即可读取活动列表，不需要任何账号信息

## 工作原理

小蚕惠生活是一个 Flutter 应用，但业务请求走的是 Android 侧的 OkHttp，通过一个统一网关 RPC：`POST https://gw.xiaocantech.com/rpc`，用请求头 `servername` / `methodname` 路由到具体方法，请求体就是 JSON 参数。

对 `libapp.so`（Dart AOT）和 `classes.dex` 做静态分析（后者是壳，把拼接的多 dex 切出来再反编译即可），可以定位到请求签名逻辑，大致是：

```
X-Ashe  = MD5( MD5((servername + "." + methodname).toLowerCase()) + 毫秒时间戳 + 随机串 )
X-Garen = 毫秒时间戳
X-Nami  = 17 位随机串（登录态时会把 silkId 嵌进去）
```

签名不含请求体，也没有服务端下发的盐。也就是说只要按这个式子构造请求头，任何客户端都能调它的接口。本项目只用到了其中的活动列表查询接口，全部为只读请求。

另一件让事情变简单的事：小蚕的首页活动列表在未登录状态下就能访问，而且返回的数据比登录态更全（没有个性化过滤）。所以整个工具不需要你的任何账号信息，也就不存在 token 过期的问题。

App 结构上是两层：

```
┌────────────────────────────┐
│ uni-app (Vue3) 编译的 H5   │ 界面层：活动列表、搜索、设置
├────────────────────────────┤
│ XcBridge (JS 桥)           │ 配置读写 / 触发抓取 / 权限管理
├────────────────────────────┤
│ Android 原生壳             │ OkHttp 请求与签名 / 前台服务巡检
│                            │ 系统通知 / 定位 / 本地 HTTP 服务
└────────────────────────────┘
```

原生壳里起了一个 127.0.0.1 的微型 HTTP 服务来加载 H5 资源（绕开 file:// 协议下 ES Module 的 CORS 限制），界面和原生之间通过 addJavascriptInterface 通信。

后台巡检是独立的 Foreground Service：定时拉取活动列表，和上一次的结果做差分，发现新的活动 ID 或名额从 0 恢复时发系统通知。请求的频率特征和人工打开 App 刷新是一样的，间隔带随机抖动，夜间静默时段完全不出网。

## 目录结构

```
web/        uni-app 前端（界面）
app-shell/  Android 原生壳（网络、巡检、通知、定位）
```

## 本地构建

需要 JDK 17、Android SDK（platform 34 + build-tools 34.0.0）、Node 18+。

```bash
# 1. 编译 H5
cd web
npm install
npm run build:h5

# 2. 打 APK（会自动把 H5 产物放进 assets）
cd ../app-shell
./build.sh
```

产物在 `app-shell/build/xc-sentinel.apk`。debug 签名，首次构建会自动生成 keystore。

## 使用

安装后打开，App 会依次申请定位和通知权限。设置页里有一个权限检查清单（含电池优化白名单和 MIUI 自启动指引），照着点亮即可。默认匿名模式，什么都不用填，切到监听设置点启动就行。想监听特定店铺就在关键词列表里加店名，模糊匹配，写「茶百道」也能命中「茶百道（石排店）」。
